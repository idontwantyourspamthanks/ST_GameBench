Requirements and usage: as in README.TXT (2 MB RAM minimum).
Run RUNME.TOS from a hard disk / GEMDOS drive, with FILES\ next to it.
Tested on Hatari 2.6.1 (see the note below).

The original game keeps its statesaves on the HD build: keypad / saves the
game state to GS00.TOS, GS01.TOS, ... in the folder HAGA runs from (it looks
for C:\GAMEX\ first). In-game SAVE GAME / LOAD GAME do not work in PP's build
even unpatched (they crash); use the HAGA statesaves.
