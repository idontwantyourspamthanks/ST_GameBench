4. Who writes it (pexec_probe4.py: arm at the loader's first instruction `pc = $fc6c`, then `b a7 < $fbc0 && a7 > $fb6c`):
   Pexec(3,"demo.tos") ... Mshrink(0xFEAC, 0xA3154) ... Malloc(0x16600)   <- the payload Malloc, then the payload read by XBIOS Floprd
   hit: D6 0000001F D7 00000004 A0 000004DE A6 FFFF8606 A7 0000FBBA  USP 0000FC4C  SR=2608  Prefetch 00e03c64 08380001   `00e03c62 bsr.b $00e03cae`  (flopcmd, ROM)

   so the stack grows down through the command line ($FBEC-$FC6C), then through the process descriptor ($FB6C+$30..$7F: handle count at +$3a, handle table at +$3c).
