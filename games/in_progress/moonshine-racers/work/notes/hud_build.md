# Moonshine Racers: the new HUD (layout A) and no clouds, built and gated

Machine for every number: Hatari 2.6.1, STE TOS 1.62 1 MB 8 MHz 50 Hz unless named; emulator gates marked **[emu]** run the exact Unicorn 68000 model of the race pass (`work/extrap/emu.py`, no VBL/raster: indices and RAM only). Raw outputs are in `work/hud/build/res_*.txt` and pasted below.
`[INFERENCE]` marks what no tool output here proves. Design/mockups: `work/notes/hud_design.md`, `work/hud/design/layout_A*.png`; element analysis: `work/notes/hud.md`.

## 0. What was built

Three patches that are the new default (`list` shows them) and four small ones around them:

| patch | site | what |
|---|---|---|
| `hd_stage` | `$ef7a` (the HUD stage, once per pass from `$7b4c`) -> `jmp $BB004` | the whole new HUD. Blob `$BB000-$BDFFF` generated by `tools/msrhudgen.py` (do not edit `patches/hd_stage.s` by hand). Calls, in the stock order: `TOPBAR` (new strip), the message ticker `$11ef0` (its state machine `$11ab/$11b1` gates the race-end flow: kept), the face `$f90c`, `HIT` (the non-display part of the old cup routine `$f620`: `$11ce` hit flag -> sound `$36`, slosh counter `$11cf`, evolving exactly as stock). Dropped calls: `de1c f1c0 efc6 f214 f3b6 f430 f53c f620(draw) f76a f7f0 de6c f22c f134` |
| `hd_init` | `$edea` (`jsr $dd18`, cloud slot init in the race init, runs for every race start and restart) -> `jsr $BB700` | clears the `painted` byte of both buffers' shadows: the first pass into each buffer repaints strip + sky |
| `hd_clouds` | `$7b3a` (`jsr $dd50`, cloud position update) -> 3 nops | removes the cloud update; with `hd_stage` there is no cloud erase/draw either |
| `hd_nomap`, `hd_nomap2` | `$f9dc` (face: map-offset + `jmp (a2)` into the mask kernel `$3a70`) -> `rts`; `$120d6` (ticker glyph: `lea $6f000`, `jmp $1237c`) -> `rts` | bypass of two occupancy-map writers in the speech path (section 6) |
| `mx_sync` (edited) | the private `hud:` list of the extra frames | now `TOPBAR`, ticker with saved/restored state, face; the `dd50` call, the `$11ca` puff animation, the `$11ce` clear and the undo ranges `$10bc,2 $11c4,12 $29c8+n*$38,4` are gone. `mx_sync requires hd_stage` |
| `test_hdref` (not default) | `$ef7a` | gate reference only: the stock stage reduced to ticker + face |
| `mr_map`, `mr_digit` | | `default: no` (dead: minimap kernel `$12690` only via `f22c`, score kernel `$14d98` only via `11d42` <- `f428`); files kept |

Strip (rows 0-15, black = palette index 2, text white): `SCORE` (5 digits of `$11c2` + constant 0, the game's 8x14 digit font) | stopwatch (`$10ce` hi byte >> 3 = 32 hand angles, 16x16) | `#` position `$10ca` (1-99) | speed = high word of `$10d8` (3 digits) `MPH` | `G` gear 1/2 (`$11d9` = 0 / non-zero) | `T` temperature `$10ba` clamped 0-35 (salmon/dark-red digits from 28 up) | turbo cup icon + 28-pixel gauge (`$10c0` clamped 0-28).
Palette A colour 14 (`$3cf0`, clouds' colour, the only other user of it in rows 0-73 apart from 24 face pixels and a few horizon pixels on 4 tracks) is set to `$777` every pass: white text. During the end-of-race bonus count (`$11c6`) the score digits use yellow/dark red (the stock `$cd` colours).
Cost of the stage (**[emu]** idle compare chain, measured below): the strip is compared field by field with a per-buffer shadow; a field is redrawn only when it differs from what THAT buffer shows (so each change is drawn once per buffer, extras and any number of passes in between need no flag bookkeeping).
Memory: `$BB000` code, `$BB700` hd_init, `$BB800` strip bitmap (2,560 B), `$BC200` glyph strips (3 sets x 11 x 64 B: white/shadow, hot, highlight), `$BCA40` gauge rows (29 x 24 B), `$BCD00` cell offsets, `$BCD20` decimal pairs, `$BCF00/$BCF40` shadows (64 B each, data), `$BCF80` scratch, `$BD000` dial images (32 x 128 B). Payload 47,360 B (`$B2700-$BDFFF`; limit 61,440).

HUD-private variables that stop being updated (all display-only, proven by the state gate, section 2): `$100c` kernel scratch; thermometer `$10bc-$10bd $11c9`; puff erase pointers `$10c2-$10c9`, puff animation `$11ca-$11cb`; position cache/flag `$10cc-$10cd $11cc`; dial cache/flag `$10d4-$10d7 $11cd`; minimap `$10dc-$10e3`; score cache/flag `$11c4-$11c5 $11c7`; lever animation `$11da-$11dc`; text buffers `$6172-$618f`; cloud slots `$29c8-$2c67` and cloud counters `$27de-$27ed` (`dd50`); the occupancy map `$6f000-$6ffff`. `$11ce`/`$11cf` are NOT in the list: `HIT` evolves them like stock.
