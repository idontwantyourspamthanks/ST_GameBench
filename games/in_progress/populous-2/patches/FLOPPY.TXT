Populous 2 (Atari ST) - patched FLOPPY build, {DATE}
Release v@VERSION@ enhanced by dad_prg

One bootable 720K disk with the whole game: the patched RUNME in AUTO\ (TOS
runs it at boot), HAGA, the STE cover picture and FILES\ (the game data).

CHANGES (as in the hard-disk version)
  Fixed game speed of 6.25 turns per real second on every machine at 50 and
  60 Hz; the game now runs at 60 Hz; faster sprites and pointer with the same
  picture; tooltips with each icon's name and key; garbled mouse packets no
  longer crash the game; the manual question (Zeus's statue question) is
  skipped. The floppy also needed a fix for TOS 2.06 (the drive head
  position after PP's loader).

DISK LAYOUT
  AUTO\RUNME.PRG   the game's start program (PP's RUNME.TOS, patched)
  HAGA             PP's disk service
  FP2273.HST       cover picture (STE hi-colour; a plain ST or TT/Falcon
                   simply skips a picture it cannot open)
  FILES\           P2CR.TOS, P2D, P2M.FIC - the game

STARTING
  Put the disk in drive A and reset (or run A:\AUTO\RUNME.PRG). Hold Space
  through PP's hardware screen, the cover, the logo and the credits; the
  main menu follows (it shows "v@VERSION@ enhanced by dad_prg").

MEMORY
  2 MB RAM minimum (PP's conversion; 1 MB does not work).

MACHINES
  ST, STE and Mega STE (TOS 1.x and 2.06). On a TT or Falcon the floppy does
  not start the game (PP's loader, unpatched too, under Hatari): use the
  hard-disk version there, which runs on both.

SAVING (needs the second disk, Populous2_save.st)
  The game disk is full, so the game's own SAVE GAME / LOAD GAME use a separate
  formatted disk in drive A: Populous2_save.st (a blank 720K disk, 12 saves of
  56,690 bytes each; write it to a real disk or keep copies of the .st).
  Open the requester (first strip icon) and click SAVE or LOAD: while the game
  disk is still in the drive the game asks INSERT SAVE DISK. Swap the disks,
  click OK, type a name in FILE, click SAVE / LOAD. The saves are NAME.GAM
  files in the root of the save disk, and the list shows them. Leave the save
  disk in the drive while you play: the game needs the game disk only to start.
  A full or write-protected save disk gives DISK FILE ERROR. The save is on the
  disk when the game returns to play. Do not use the game disk for saving.
  (HAGA's keypad / statesave still does not fit on a floppy.)
