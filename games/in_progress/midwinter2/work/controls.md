# Midwinter 2 in-game controls (from the manual, pp. 145–154)

All vehicles share this base layout unless noted. Mouse axes and joystick directions act on *rates* (the "yoke" model we intend to replace).

| Action | Mouse | Joystick | Keyboard |
|---|---|---|---|
| Speed up / slow down | up / down | up / down | numpad 8 / 2 |
| Turn left / right | left / right | left / right | numpad 4 / 6 |
| Nose down / up | LMB / RMB | `<` / `>` | `<` / `>` |
| Fire | Space | fire | Space |
| Weapon select | + / - | + / - | + / - |
| Exit vehicle (human mode) | Esc | Esc | Esc |

The pitch row (nose down/up) applies to: Flying Sub, Tank (barrel), Jeep, Minisub, Biplane, Helicopter, Zeppelin, Flying Boat, and the on-foot, swim and frogman modes.

The following vehicles have no pitch row:
- Truck
- Bus
- Speedboat
- Crawler
- Submarine
- Ship
- Hovercraft

**Exceptions:**

- **Train:** speed only. Cursor up/down turns the train around.
- **Submarine:**
  - Mouse: vertical velocity on L+R mouse buttons together.
  - Joystick: `>` raises, `<` lowers.
  - Keyboard: cursor up/down.
- **Helicopter and Zeppelin:** vertical velocity on cursor up/down.
- **Balloon:** no speed control.
  - Mouse/joystick: up = nose down, down = nose up; vertical velocity on L+R mouse buttons, or `>`/`<` on joystick.
  - Keyboard: `<` = nose down, `>` = nose up.
- **Parachute:** same layout as the Balloon (no speed control).
- **Rocket pack:**
  - Speed: RMB up, LMB down (`>` / `<` on joystick or keyboard).
  - Mouse/joystick up/down = vertical velocity; on keyboard, numpad 8 = up, numpad 2 = down.
- **On foot:** cursor keys zoom the rifle sight.

Observed in the harness while on foot in mouse mode:
- Moving the mouse forward raised the speed readout 0 → 5 → 15.
- Moving it back lowered the speed again.
