# Exemplars

Reference programs by other authors that show how a technique runs fast on the Atari ST/STE. They are studied, not modified or shipped.
The program files themselves are git-ignored (`**/*.st`, `**/*.ST`): only this README is tracked.

| Folder | File | What it is | Why it is here |
|---|---|---|---|
| `2d-racing/` | `lotus_esprit_turbo_challenge_ste_1_0_[thomas_jonathan].st` | an STE-only upgrade of Lotus Esprit Turbo Challenge, made a few years ago (author tag in the file name) | how a racing game can run fast on an STE (road, sprites, blitter, scrolling); study notes for Moonshine Racers: `games/in_progress/moonshine-racers/work/notes/lotus_exemplar.md` |
