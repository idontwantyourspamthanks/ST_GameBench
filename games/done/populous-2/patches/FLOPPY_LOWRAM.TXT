Release v@VERSION@ enhanced by dad_prg

WHICH VERSION TO USE (three builds of this release)
  Hard disk (folder POPS2)   ST, STE, Mega STE, TT, Falcon; 2 MB RAM or more.
                             In-game SAVE/LOAD to NAME.GAM files in FILES\
                             (not on the Falcon: use HAGA's statesave there).
  Floppy (Populous2_boot.st) ST, STE, Mega STE; 2 MB RAM or more.
                             Saves go to a separate save disk (included).
                             Does not start on a TT or Falcon.
  Low-RAM floppy             ST, STE, Mega STE, Falcon; TT at 8 MHz only.
  (Populous2_lowram.st)      512 KB RAM or more (the plain-ST sprite speed-up
                             needs 1 MB). Saves on the game disk, 3 slots.
  All three have the same enhancements (fixed 6.25 turns/s speed, 60 Hz,
  faster sprites and pointer, tooltips, no manual question).

One bootable 720K disk with the whole game, built on the 1991 ICS release of the
floppy game (the original Bullfrog files and its own loader, minus the ICS intro
screen). It runs in 512 KB of RAM and the game's own SAVE GAME / LOAD GAME work
on it, on the game disk itself, with room for 3 saves.

Populous2_lowram.st is a 720K .st disk image (9 sectors, 2 sides, 80 tracks);
write it to a real disk or load it as drive A: in an emulator.

WHAT IS DIFFERENT FROM THE OTHER TWO BUILDS
  - Runs in 512 KB (ST, STE; also 1 MB and more, TT/Falcon: see MACHINES).
    The other floppy needs 2 MB.
  - SAVE GAME / LOAD GAME work on this disk, like in the original release; no
    second disk. The game writes NAME.GAM files (56,690 bytes) to the game disk.
    The disk has room for 3 saves. Do not write-protect the disk if you want to
    save; keep a copy of the .st.
  - The manual question (Zeus's statue question) is skipped.
  - The sprite cache for the plain ST (a speed-up for machines without a
    blitter) is only in the 1 MB+ layout: with 512 KB a plain ST draws sprites
    with the game's own code, like the original. The STE blitter speed-up, the
    tooltips, the 60 Hz and fixed-speed tick, the pointer redraw skipping and
    the bad-mouse-packet filter are the same in 512 KB and above.

STARTING
  Put the disk in drive A and reset. The Bullfrog logo and the credits follow;
  hold Space through them if they wait for a key. The main menu shows
  "v@VERSION@ enhanced by dad_prg" in the lower part of the slate panel.

MEMORY AND MACHINES
  512 KB RAM minimum (the game image ends at 505 KB); 1 MB and more use a
  second copy of the same patches with a pre-shifted sprite cache for the plain ST.
  Tested in Hatari 2.6.1 (not on real hardware): ST TOS 1.04 512 KB, STE TOS 1.62
  512 KB and 1 MB, Mega STE TOS 2.06 4 MB at 60 Hz, Falcon TOS 4.04 4 MB.
  Play, saving and loading all work on those. TT (TOS 3.06): set the CPU to
  8 MHz. At the default 32 MHz the game's own floppy routine fails and it shows
  INSERT POPULOUS-II DISK; the original ICS disk does exactly the same there
  (it is the game's FDC timing on a fast CPU), so this build cannot fix it. The
  hard-disk version runs on a TT at full speed.
