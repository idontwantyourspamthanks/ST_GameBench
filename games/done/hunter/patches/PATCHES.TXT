Hunter (Activision 1991) - patched build of PP's Gamex hard-disk version
Release v@VERSION@ enhanced by dad_prg

What changed against the original release:
- Faster 3D view on a stock 8 MHz ST/STE, pixel-identical to the original:
  * the polygon filler was rewritten (rows outside the screen are skipped, edges are walked in blocks),
  * the edge set-up avoids the slow divide when it is not needed,
  * the joystick poll in the 50 Hz interrupt no longer waits 350 microseconds each time.
  Together this is about 6.5% (standing) to 13.7% (walking) fewer CPU cycles per frame.
- STE sound (STE, Mega STE, TT, Falcon): the YM sound effects are replaced by the Amiga
  version's samples, played through the STE DMA sound chip (mono, 6258 Hz, two voices;
  the Falcon's DMA cannot do 6258 Hz, there it runs at 12517 Hz with every sample doubled).
  The engine pitch follows the speed, as on the Amiga. Costs about 0.2% of the CPU when
  nothing plays, up to about 10% with two sounds. A plain ST keeps the original YM sound.
- 50/60 Hz: the original game counts display refreshes. It asks the shifter for 50 Hz when it starts, but wherever the
  screen runs at 60 Hz anyway (hardware or an adapter that ignores that, an emulator set to 60 Hz) everything that moves or
  counts down ran 20% too fast: walking and driving, turning, NPCs, projectiles, the game clock, stamina and message
  timers, and the length of the sound effects. Now the world runs in real time at 50 and 60 Hz (50 "world ticks" per second
  whatever the refresh; 5 of every 6 refreshes at 60 Hz). At 50 Hz the game plays exactly as before.
- Atari Jaguar pad (new in v1.1; STE and Falcon enhanced joystick ports, either port, two pads work too): the d-pad steers
  like the joystick and A or B is fire. Keys: C = Return, Option = Space, Pause = P, * = Esc, 1 = R, 2 = Help, 3 = L,
  4 = A, 5 = F, 6 = C, 7/9 = cursor up/down. Menus stay mouse-driven. Each button is read every 80 ms, so a very
  short tap can be missed. Machines without the ports (ST, Mega ST, Mega STE, TT) run exactly as before, with no cost.
- TT (new in v1.1): a TT booting from hard disk was taken for a Falcon by the sound code, which then used the Falcon's
  rate. It now plays at the STE rate, as on the floppy.
- Version line: the title screen shows a small, dim "v@VERSION@ enhanced by dad_prg" at the bottom, so this release can not be
  mistaken for the original. Nothing else on the screen changes.
- Every patch checks the original bytes it replaces first. If anything is not as
  expected, nothing is changed and the game starts as before.
- Nothing else in the game is changed: keyboard, mouse and joystick controls and saves work as in PP's release, and at 50 Hz so does the game speed.

How it is delivered:
- START.TOS is replaced by a patched copy (unpacked); it also reads the extra file FILES\P
  (patch code plus the sample bank) through the game's own disk loader, then starts the game.
  If FILES\P is missing the game starts unpatched.

Requirements and usage are as in README.TXT (1 MB RAM minimum).
Run START.TOS from a hard disk as before (PP's HDDRIVER / AHDI setup).
Tested on Hatari: STE (TOS 1.62) at 1 MB and 4 MB, Mega STE (TOS 2.06) at 4 MB, ST (TOS 1.04) at 1 MB, TT (TOS 3.06) at 4 MB;
the Jaguar pad on the STE (HD and floppy) and the Falcon (TOS 4.04, floppy).
Not tested on real hardware.
