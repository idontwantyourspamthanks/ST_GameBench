# Nebulus (PP's Gamex hard-disk build)

Status: **in progress** — planning, boot harness working.

Nebulus (1987, Hewson; ST version by John M. Phillips), PP's Gamex HD repack (START.TOS + NEBEXE.FIC).
1 MB minimum, 512 KB for gameplay.

- Boot chain and why Hatari's GEMDOS drive fails: `work/notes/` (Hunter's `boot.md` documents the same Gamex chain).
- Harness: `tools/nebulus.py` (builds a bootable ACSI image with HDDRIVER, autoruns START.TOS).
- Plan: `PLAN.md`.
